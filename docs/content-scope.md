# 冬瓜站内容边界

面向不会编程、借助 AI 独立做产品的人。每篇回答把网站、小程序、App、桌面软件做出来、上线、收款和维护中的一个具体卡点。

允许：需求取舍、开源底子、AI 编程工具与沟通、运行预览、部署域名备案、产品所需账号资质、支付审核、上线后的排障与获客。技术词本身不违规；SSH、DNS、HTTPS、CORS 等必须写成新手可执行的任务：交给 AI 的提示词、本人必须做的操作、验收和失败后的下一步。

禁止：面向专业开发者的算法源码、框架实现、性能底层或容器集群教程；泛 AI 新闻、泛创业副业鸡汤、通用营销；脱离个人产品的工商财税教程；安全防护关闭教程；规避地区或审核限制。合法签名、解释误报与正式申诉可以写，不能把关闭安全防护当解决方案。

选题必须说清：谁被卡住、在哪个产品阶段、解决后能做什么。财税资质等边界题必须回到个人产品的实际上线/收款条件，只引用官方规则，不作法律财税承诺。不能靠文末加一段广告或「用 AI」就让无关文章变相关。

相同答案的不同问法放 covers/FAQ，不拆文章。缺相关且可核实的题可以少发并报告原因，不能为了周目标凑稿。独立核查把受众或主题偏离列为 high；事实正确不等于适合发布。
