找外包做小程序，要先说清需求、谈价格、等排期；**自己用 AI 做**，你只需要把想法说清楚，代码交给 Claude Code 或 Codex，你负责决定、验收，以及注册账号、选类目、备案、提交审核这些只能本人做的事。

小程序比网站多三道关：**注册主体和类目**（个人主体能选的类目有限，动手前先查清）、**小程序备案**、**平台审核**。下面按上线流程列出每一步要看的内容。


<h2 id="filing">小程序备案入口在哪里，被驳回后怎么改？</h2>

进入小程序管理后台，查看设置中的小程序备案入口或首页备案提示。备案要按实际主体、服务内容和所在地要求填写；代码审核与备案各有待办，不能把代码审核通过当作备案完成。

如果备案被驳回，从后台首页的「小程序备案」查看驳回原因，记录要求修改的字段、待完善原因和修改建议。先对照证件及真实业务修正这些字段，再重新提交；不要只把同一份资料原样提交一遍。收到工信部核验短信后，按要求在24小时内完成核验，并在审核期间保持负责人电话畅通。

例如，后台提示填写信息与证件图片不一致，就逐项核对姓名、地址或证件号码，修正识别错误或重传清晰图片；不要为了通过而填写不真实信息。AI可以帮你解释遮住私人信息后的驳回说明和整理清单，身份核验与正式提交仍由你本人完成。

以上入口与处理方式于2026年11月17日核对[微信官方备案常见问答](https://developers.weixin.qq.com/miniprogram/product/record/record_faq.html)。实际补充材料按本人后台要求办理。打算收费时，另看[个人小程序虚拟支付条件](/flow/payment/#sec-personal)；备案完成不等于支付已经开通。
