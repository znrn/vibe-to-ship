> 搜索平台的菜单和规则以百度搜索资源平台、Bing Webmaster Tools 官方说明为准。用 Claude Code 或 Codex 前，先确认服务在你所在地区可用，遵守服务条款。

## <span class="role-tag ai">🤖 交给 AI</span> 网站挂了：先看再改

网站打不开，先别自己乱点。把现象、截图、出问题前做过什么告诉 AI，让它连上服务器**只看不改**，用大白话说清原因，你同意了再动手。常见的是程序停了（显示 502）、证书过期、磁盘满了。

做法和处理报错一样：一次只修一个，修完自己用手机打开看一遍。怎么在网站挂掉时第一时间知道，<mark class="todo">待定</mark>（冬瓜用不用监控工具、用哪个，还没定）。

## <span class="role-tag ai">🤖 交给 AI</span> 更新版本：照部署说明来，改坏了先回退

[服务器和部署](/flow/deploy/)那一步让 AI 留了一份「部署说明.md」，以后每次更新都让它照这份来。更新前先存版本，更新后用手机流量走一遍核心功能。

更新后出问题，**先回退，再查原因**：让 AI 把线上回到上一个能用的版本，网站先恢复，再慢慢找是哪里改坏了。修三四轮还乱，就回到上一个能用的版本重来，做法见[开发和报错](/flow/build/)。

## <span class="role-tag me">🧑 你来做</span> 续费别忘：域名、服务器、证书

上线后有三样东西会到期：

| 东西 | 谁来续 | 到期没续 |
| --- | --- | --- |
| 域名 | 你，在域名服务商后台付款 | 网站可能打不开，细节见服务商说明 |
| 服务器 | 你，在云厂商后台付款 | 网站可能打不开，细节见云厂商说明 |
| SSL 证书 | 让 AI 配好自动续期，你偶尔看一眼小锁 | 浏览器提示「不安全」 |

买的时候就把到期日记下来。怎么设到期提醒、提前多久续，<mark class="todo">待定</mark>。域名、HTTPS 的基础做法见[域名、备案和 HTTPS](/flow/domain/)。

## <span class="role-tag me">🧑 你来做</span> 让人找到你：提交给搜索平台

网站上线后，搜索引擎不一定马上知道它。主动提交一下：

1. 让 AI 生成 sitemap.xml（网站所有页面的清单），放在网站根目录。
2. **百度搜索资源平台**：你登录、添加网站，用文件或 HTML 标签验证归属（让 AI 帮你放），验证通过后在「普通收录」里提交 sitemap。
3. **Bing Webmaster Tools**：你登录、添加网站并验证；已经用 Google Search Console 的，可以直接导入。
4. **Google Search Console**：网站面向海外用户的再加，可选。

提交只是告诉搜索引擎「有这个网站」，百度官方也说明 Sitemap 和搜索排名无关。之后靠的还是页面本身有没有人需要。除了搜索，还能怎么获客，<mark class="todo">待定</mark>（冬瓜常用的推广渠道还没整理）。

## <span class="role-tag me">🧑 你来做</span> 收集反馈，决定下一版

第一版就该留一个反馈入口。反馈攒多了，整段发给 AI 分类排序：哪些是 bug、哪些是新需求、哪些提的人最多。做不做、先做哪个，你来定。定好了，回到[想清楚做什么](/flow/idea/)，开始下一版。
