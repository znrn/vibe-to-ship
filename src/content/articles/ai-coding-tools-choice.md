> 工具和价格变化很快：本文的价格和套餐核对于 2026 年 10 月 27 日，**以各家官网当前说明为准**。海外工具请先确认它在你所在地区提供服务，遵守服务条款。

## 先分清三类 AI 工具

| 类型 | 代表 | 适合做什么 | 上手门槛 |
| --- | --- | --- | --- |
| **AI 对话工具** | 豆包、DeepSeek、Kimi、通义千问；ChatGPT、Claude | 一个网页、问问题、看懂报错 | 最低，网页或 App 打开就能用 |
| **AI 编程编辑器** | TRAE、Cursor，或 VS Code 加通义灵码插件 | 多个页面的完整项目，AI 直接改你电脑上的文件 | 要装软件，会打开一个项目文件夹 |
| **AI 编程智能体** | Claude Code，以及 OpenAI 的 Codex | 交给 AI 一整件事，它自己规划、改多个文件、运行命令 | 最高，常要用到终端；目前以海外服务为主 |

三类不是谁替代谁，而是**项目越大，越往下走**：

- 只做一个介绍页、作品集：对话工具就够，做法见 [不会写代码怎么做网页](/articles/website-without-coding/)。
- 要做好几个页面、加表单、接数据：对话工具里来回复制粘贴会越来越乱，这时换 AI 编程编辑器，让 AI 直接在项目文件夹里改。
- 编辑器也用顺了、项目越来越大：再考虑编程智能体。

## 国内能直接用的 AI 编程工具

### TRAE（国内版）

独立的 AI 编程软件，下载安装后直接用。核对时的定价：

| 档位 | 价格 |
| --- | --- |
| Free | 免费，每月 500 积分，所有功能都能用 |
| Lite | ¥49 / 月（首月有优惠） |
| Pro | ¥99 / 月（首月有优惠） |
| Pro+ | ¥239 / 月 |
| Ultra | ¥699 / 月 |

### 通义灵码

阿里云出的 AI 编程助手，可以装进 VS Code、Visual Studio、JetBrains 等常用编辑器里当插件用，也有自己的 Lingma IDE。官网写明**个人免费使用**。

不会编程的话，推荐先装免费的 VS Code，再在里面装通义灵码插件。

## Cursor 和 Claude Code 怎么选

两个都是海外工具，能力强，网上教程多，但使用前要先看清两件事：**能不能用**和**花多少钱**。

**Cursor**：一个 AI 编程编辑器，和 TRAE 是同一类。它的定价最近调整过，核对时个人版是：

| 档位 | 价格 | 说明 |
| --- | --- | --- |
| Free | $0 | 有限的 Agent 和对话次数 |
| Plus | $8 / 月 | 只能用 Grok 模型 |
| Premium | $30 / 月 | 用量是 Plus 的 4 倍，能用第三方模型，第三方模型按 API 价另计 |
| Super / Ultra | $100 / $200 每月 | 更高用量 |

**Claude Code**：Anthropic 出的编程智能体，可以在终端、VS Code 和 JetBrains 插件、桌面应用、网页里用，大多数用法需要 Claude 付费订阅或 Anthropic 开发者账号。要注意的是，**Anthropic 的官方支持地区列表里没有中国内地、香港和澳门**，在这些地区不提供服务。

所以怎么选：

- **人在中国内地**：先用 TRAE 或通义灵码，能力足够做出第一版产品。
- **人在受支持的地区、并且合规使用**：可以按需要的能力和预算在 Cursor、Claude Code 里选。Cursor 上手更像普通软件；Claude Code 更擅长「交给它一整件事」。

## 三条省钱建议

1. **先用免费档做出第一版**。做一个能让别人用的页面，免费额度通常够用。
2. **卡住了再升级，按月买**。工具和价格变化快，年付很可能半年后就不划算。
3. **把钱留给上线**。域名、服务器、执照这些是绕不过去的成本，AI 工具反而有很多免费选项。
