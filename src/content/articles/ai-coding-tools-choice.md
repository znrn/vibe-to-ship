## <span class="role-tag me">🧑 你来做</span> 先想清楚：你要的是「能自己动手的 AI」

不会编程的人用 AI 做产品，最省事的不是「AI 帮你写一段代码，你复制粘贴」，而是「你说要什么，AI 自己做完」。所以选工具只看一件事：**它能不能自己动手**。

| | AI 对话工具 | AI 编辑器 + 插件 | AI 编程智能体 |
| --- | --- | --- | --- |
| 代表 | 豆包、DeepSeek、Kimi、通义千问 | Cursor、TRAE、VS Code 加通义灵码 | **Claude Code、Codex** |
| 谁在动手 | 你：复制代码、保存文件、运行 | 你在编辑器里看代码，AI 帮你改 | **AI：建项目、改文件、运行、部署** |
| 适合谁 | 查资料、解释报错 | 会写代码、想写得更快的人 | **不会写代码、只想把产品做出来的人** |

冬瓜的做法：**直接用 Claude Code 或 Codex**，两个都在用。新建一个项目文件夹，用大白话说想法，让它先去找有没有现成的开源项目可以改，没有再从零写，做法见 [选底子：开源二开还是从零写](/flow/base/)。

## <span class="role-tag ai">🤖 交给 AI</span> 订阅好以后，从说想法开始

工具装好后，不用学任何界面，直接在项目文件夹里对它说：

> 「我想做一个 [给谁用、解决什么问题的东西]。先别写代码，帮我把第一版要做的功能列出来，再看看有没有现成的开源项目可以拿来改。」

后面怎么一步步做、出了报错怎么办，见 [开发和报错](/flow/build/)。

## 核对时的价格

各家都按月订阅，下面是本文核对时的官方价格，变动以官网为准：

| 工具 | 类型 | 免费能用吗 | 付费起步价 |
| --- | --- | --- | --- |
| Claude Code | 编程智能体 | 不能，需要 Claude 付费订阅或 Anthropic 开发者账号 | 以 Anthropic 官网为准 |
| Codex | 编程智能体 | 以 OpenAI 官网为准 | 以 OpenAI 官网为准 |
| Cursor | AI 编辑器 | 能，额度有限 | $8 / 月（这一档只能用 Grok 模型） |
| TRAE 国内版 | AI 编辑器 | 能，每月 500 积分 | ¥49 / 月（原价，首月有优惠） |
| 通义灵码 | 编辑器插件 | 个人免费 | 官网未列个人付费档 |

两点提醒：

- **Anthropic 的官方支持地区列表里没有中国内地、香港和澳门**，在这些地区不提供服务。
- **先按月买最低能用的一档**，做出第一版再看用量。工具和价格变化快，年付很可能半年后就不划算。
