> 本文适合做产品介绍页、作品集、活动页这类**一个页面**的网站。要做登录、付款、后台的完整产品，先用这个方法把第一页做出来，再一步步加。

## 做网页需要写代码吗

网页说到底就是一个 HTML 文件，浏览器打开它就能显示出页面。以前这个文件要自己一行行写，现在可以完全交给 AI 写。

你的工作变成三件事：

1. **说清楚要什么**：给谁看、页面上有哪些内容、希望看的人做什么。
2. **看效果**：在浏览器里打开，对照自己想要的样子。
3. **提修改**：用大白话告诉 AI 哪里不对、想改成什么样。

## 零基础做网站用什么软件

| 用途 | 用什么 | 说明 |
| --- | --- | --- |
| 写代码 | 任意 AI 对话工具 | 豆包、DeepSeek、Kimi、通义千问，或 ChatGPT、Claude，哪个顺手用哪个 |
| 保存文件 | 纯文本编辑器 | Windows 记事本，或免费的 VS Code；Mac 自带的「文本编辑」要先切成纯文本 |
| 看效果 | 浏览器 | 电脑上已经有的 Chrome、Edge、Safari 都行 |
| 放上网 | Netlify Drop 或 Cloudflare Pages | 拖拽上传，不用写命令，下面第 4 步细说 |

第一个网页用对话工具就够了。等你要反复改很多页面，再考虑 Cursor 这类专门的 AI 编程工具。

## 第 1 步：用一句话说清楚要做什么

动手前先写下这句话，后面所有修改都以它为准：

> 这个网页给 **谁** 看，帮他 **解决什么问题**，看完希望他 **做什么**。

例如：「给想学 AI 做产品的上班族看，介绍我的周末实战营，看完希望他加我微信报名。」

## 第 2 步：让 AI 写成一个 HTML 文件

把下面这段改成你自己的内容，发给 AI：

```
帮我做一个网页，给想学 AI 做产品的上班族看，介绍我的周末实战营。
页面要有：一句话标题、三个卖点、课程安排、一个「加微信报名」的按钮（先用文字写微信号）。
要求：
- 只要一个 HTML 文件，样式写在同一个文件里，不要引用我电脑上的其他文件
- 手机和电脑上都要好看
- 不要登录、不要数据库、不要后台
- 图片先用色块占位，我之后再换
```

几个要点：

- **「只要一个 HTML 文件」**最重要。文件一多，保存、上传都容易出错。
- **先不要图片**。图片要单独保存、路径要对得上，第一版用色块占位最省事。
- **一次只做一件事**。先把页面做出来，再谈好不好看。

## 第 3 步：在自己电脑上看效果、继续改

1. 新建一个文件夹，比如叫 `my-site`。
2. 把 AI 给的代码完整复制，用纯文本编辑器保存为 `index.html`，放进这个文件夹。
3. 双击 `index.html`，浏览器会直接打开它，这就是你的网页。

哪里不满意，就用大白话告诉 AI，**说清楚位置和想要的样子**：

- 「标题太小了，手机上看不清，放大一些，颜色改成深绿色。」
- 「三个卖点在手机上挤成一排了，改成上下排列。」
- 「按钮下面加一行小字：名额有限，每期 8 人。」

每次让 AI **给出修改后的完整文件**，整个替换掉 `index.html`，比自己找位置改一两行更不容易出错。改出满意的版本后，复制一份存成 `index-v1.html` 留底，后面改坏了还能找回来。

## 第 4 步：放上网，拿到一个网址

现在网页只在你自己电脑上。把整个 `my-site` 文件夹上传到下面任意一个平台，就能得到一个公网网址：

| | Netlify Drop | Cloudflare Pages |
| --- | --- | --- |
| 怎么传 | 打开 `app.netlify.com/drop`，把文件夹拖进去 | 控制台里选 Workers & Pages → Create application → 拖拽上传文件夹或 zip |
| 要不要账号 | 不登录也能发布，建议注册，方便以后更新 | 需要 Cloudflare 账号 |
| 得到的网址 | 系统分配的网址 | `项目名.pages.dev` |
| 限制 | 单页网站基本碰不到 | 拖拽上传最多 1000 个文件，单个文件不超过 25 MiB |

两个都不用写命令、不用买服务器。上传后把网址发到手机上打开，确认能看。

要注意：这两个都是**海外服务**，国内用户打开的速度和稳定性没有保证，适合先给自己、朋友和第一批用户看。打算长期面向国内用户，就要换成国内服务器并做 ICP 备案，流程见 [ICP 备案流程：个人网站首次备案的 5 个步骤](/articles/icp-filing-process/)。

## 第一版别急着做这些

登录注册、在线支付、管理后台，每一样都能卡你好几天，又都回答不了最重要的问题：**有没有人想要**。先用一个页面把想法讲清楚、收集到第一批意向，再决定要不要往下做。为什么这样做、单页上应该放什么，见 [第一个产品先别做登录和支付：今天就能上线的单页](/articles/single-page-first/)。
