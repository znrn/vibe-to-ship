> 本文针对已完成 ICP 备案的个人网站。办理材料、表单和核验要求，以全国互联网安全管理服务平台及属地公安机关网安部门的实际要求为准；云厂商文档用于辅助填写。

## <span class="role-tag me">🧑 你来做</span> 先判断：我的网站现在要办公安备案吗？

如果你已经拿到 ICP 备案号，网站也已经对外开放，就把公安联网备案接着办完。阿里云的[个人网站备案指引](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)明确要求：开通网站之日起 **30 日内提交申请**。

如果网站还没实际搭建上线、无法通过公网访问，腾讯云的[通用指引](https://cloud.tencent.com/document/product/243/19142)说明可以暂不办理。不过，进入公安备案审核时，网站需要能够打开。

ICP 还没通过的，先完成 [ICP 备案流程：个人网站首次备案的 5 个步骤和要准备的东西](/articles/icp-filing-process/)。本页接着处理开通后的公安备案，不重复前面的 ICP 申请。

## 网站公安备案从哪里开始，怎么提交？

入口是[全国互联网安全管理服务平台](https://beian.mps.gov.cn/)。可以让 Claude / Codex 先整理填写清单，实名和提交由你本人完成。

### 先看有没有可用的数据码

数据码是把已有 ICP 资料带入公安备案的工具，不是公安备案通过凭证。

以[腾讯云的数据码指引](https://cloud.tencent.com/document/product/243/120137)为例：首次备案或新增网站服务，且在 ICP 订单审核时同意同步信息，才支持获取数据码。你可以到备案订单里的「公安联网备案」查看，再去公安平台绑定、核对并补齐信息。

没有数据码也能申请，按平台表单手动填写即可。**看到资料已经带入后，还要完成公安备案提交和审核。**

### 手动填报时，按主体和网站分开准备

按照[腾讯云通用指引](https://cloud.tencent.com/document/product/243/19142)，个人选择个人用户登录并完成实人认证；进入「业务办理 → 新增主体」，填写负责人资料，再选择「新办网站申请」。

建议先把资料分开收好：

- 本人资料留给你在官方平台填写、上传。
- 网站名称、域名、服务器公网 IP、实际功能，整理成清单供核对。
- 域名证书从域名服务商后台获取；接入商信息按下一节核实。

表单里的网站服务类型要与实际功能一致。看不懂选项时，把隐去个人信息的字段截图交给 AI 解释；最后由你确认。完成后阅读责任告知书，再提交审核。

## 公安备案网络接入服务商怎么填，去哪里查？

这里容易混淆的是：**网站由谁提供接入服务，域名由谁注册，是两个问题。** 不要把购买页面上的品牌名直接复制到所有字段。

先回到办理 ICP 的云服务商控制台，确认这次网站的接入信息，再查该服务商的公安备案填写说明。拿不准公司全称时，可以向服务商客服这样问：

> 我的网站 [域名] 正在办公安联网备案。请确认对应的网络接入服务商全称、所属区域、联系电话和网站接入方式，并给我官方填写说明。

下面只适用于**通过腾讯云完成 ICP 备案的域名**，依据是腾讯云[网络接入与域名注册服务商查询](https://cloud.tencent.com/document/product/243/105757)：

| 字段 | 腾讯云文档给出的内容 |
| --- | --- |
| 网络接入服务商名称 | 腾讯云计算（北京）有限责任公司 |
| 所属区域 | 北京市市辖区海淀区 |
| 网站接入方式 | 租赁虚拟空间 |
| 联系电话 | 4009100100 |

其他服务商不要照抄这张表。

域名注册商另查：使用 WHOIS，也就是域名注册信息查询。腾讯云文档还说明，在腾讯云注册的域名，如果 WHOIS 查不到，可以到「域名注册 → 我的域名 → 更多 → 下载域名证书」查看注册服务商。买域名和买服务器在同一个平台，也应分别核对这两项。

## 公安备案多久审核通过？

[腾讯云常见问题](https://cloud.tencent.com/document/product/243/19616)同一页有两种时间表述：

| 文档位置 | 原文对应的时间口径 |
| --- | --- |
| 「申请需要多长时间审核完」 | 业务申请审核时限为 30 个自然日 |
| 「具体流程」中的时间要求 | 审核周期一般为 7～20 个工作日 |

自然日和工作日不能直接混用，也不能据此承诺哪天一定通过。查看平台进度；超过文档所述审核时限仍无结果，联系属地公安机关网安部门确认。

提交前，建议自己用手机打开网站检查一次。被退回后，把审核意见中的问题逐项改完再提交；无法理解的要求直接咨询受理机关。AI 可以解释脱敏后的意见、协助排查网页问题，不能替审核机关决定是否合格。

## 不做公安备案会怎样？

不能用“网站现在还能访问”来判断手续已经齐全。[《计算机信息网络国际联网安全保护管理办法》第二十三条](https://xzfg.moj.gov.cn/front/law/detail?LawID=498)规定，违反第十一条、第十二条、不履行备案职责的，可由公安机关给予警告，或者处以不超过六个月的停机整顿。

发现漏办就尽快补办，并向属地网安部门说明情况。不要把网上的固定罚款金额、自动封站日期当成自己的处理结果；具体处理以主管机关决定为准。

## 通过后，让 AI 做什么，自己怎么验收？

按照[腾讯云通用指引](https://cloud.tencent.com/document/product/243/19142)，审核通过后要在 **30 日内**到已备案网站详情中取得备案号、图标和 HTML 代码，再添加到网站。

你不用自己改代码。把平台提供的公开备案信息交给 Claude / Codex，让它加到首页底部，先看本地预览。原有 ICP 备案信息保留，公安备案信息单独展示。

上线后亲自打开首页：号码应与平台一致，图标应正常显示，点击链接应进入平台提供的查询地址。再核对查询结果中的网站信息，避免挂了示例编号或别人的链接。

做到这里，再考虑产品的收费安排；下一步可以看 [没有营业执照，第一笔钱怎么收](/articles/first-payment-without-license/)。
