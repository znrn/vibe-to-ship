faq:
  - q: 服务器怎么连接？
    a: 用 SSH 连，需要服务器的公网 IP、用户名和密码（或密钥）。不会也没关系，把这几样信息交给 Claude / Codex，让它连；你只需要在控制台把 IP 和登录密码准备好。
  - q: 服务器怎么开放端口？
    a: 端口要在两个地方都放行：服务器里面的防火墙（AI 能改），和云厂商控制台里的防火墙或安全组（只能你自己点）。阿里云轻量应用服务器的 Linux 系统默认已放行 22、80、443，网站走这两个端口通常不用改。
  - q: 不会命令行能部署网站吗？
    a: 能。命令都由 AI 来敲，你负责准备信息、做控制台里的操作、最后验收。关键是让它每一步先说要做什么，做完告诉你怎么检查。
  - q: Vue 这类项目怎么部署到服务器？
    a: 和其他项目一样交给 AI：告诉它项目用的是 Vue，让它先在本地构建好，再把构建结果部署到服务器、用 Nginx 提供访问。你只需要说清楚项目在哪、要用什么地址访问。

## <span class="role me">🧑 你来做</span> 先判断：你真的需要服务器吗

最省钱的服务器是不买。下单之前先问 AI 一句：

> 「我的项目是 [一句话说清楚]，需要买服务器吗？有没有更简单的上线办法？」

- **只是展示页**（个人主页、产品介绍、活动页）：用免费托管就够了，拖文件夹就能上线，做法见 [不会写代码怎么做网页](/articles/website-without-coding/)。
- **要存数据、有后台程序、或者主要给国内用户用**：才需要服务器，接着往下看。

## <span class="role me">🧑 你来做</span> 买哪种：轻量应用服务器就够

- **产品**：选「轻量应用服务器」，带宽打包、控制台简单，比云服务器 ECS 好上手。
- **配置**：2 核 2G 起步，真有用户了再升级。
- **系统**：Ubuntu 的长期支持版，资料最多，AI 也最熟。
- **地域**：用户在国内选中国内地，但要先做 ICP 备案，流程见 [ICP 备案流程](/articles/icp-filing-process/)；急着上线可以先选中国香港或海外。
- **价格**：看清**续费价**，不只看首年活动价；新手别选按流量计费。

## <span class="role ai">🤖 交给 AI</span> 这些事都不用你动手

服务器买好后，下面这些全部交给 Claude / Codex：

- 用 SSH 连上服务器
- 安装网站需要的运行环境
- 把你电脑上的项目传上去，让它跑起来
- 配置 Nginx，让别人通过 IP 或域名访问
- 申请免费 SSL 证书、配 HTTPS、设置自动续期
- 设置开机自启，服务器重启后网站自己恢复

你要做的，是把信息准备好、按下面的说法交代清楚，然后**每一步都让它先说要做什么**。
