> 本文的规则以微信开放文档 2026 年 11 月的页面为准，类目和备案要求会随政策调整，**注册和设置类目时以公众平台后台的提示为准**。

## 个人能注册小程序吗？

能。微信官方对个人主体的要求只有一句：**18 岁以上有国内身份信息的微信实名用户**。不需要营业执照，也不用对公账户。

但注册之前要先想清楚一件事：**主体信息提交后不能变更**。个人注册的账号，以后不能直接改成企业。所以先判断个人主体够不够你用，再动手。

## <span class="role-tag me">🧑 你来做</span> 先判断：个人主体够不够用

只看两个问题：

1. **要不要在小程序里收钱**（卖东西、会员费、付费解锁）。要收，个人主体不行，直接看下面「个人小程序能收钱吗」。
2. **你的功能在不在个人开放类目里**。在，个人就够；不在，要换主体。

| 你的情况 | 建议用什么主体 |
| --- | --- |
| 做工具、记账、信息查询、预约报名这类，不收钱 | 个人 |
| 先做出来给朋友试用，还没想好收不收钱 | 个人（以后要收钱时用新主体另外注册） |
| 要在小程序里收钱 | 个体工商户或公司 |
| 类目不在个人开放范围内（比如网上商城） | 个体工商户或公司 |

还没有营业执照、只是想先收到第一笔钱，可以看 [没有营业执照怎么收款](/articles/first-payment-without-license/)。

## 个人主体小程序的 4 个限制

### 1. 不能微信认证，所以开不了微信支付

微信官方的接入指南写明：**个人类型账号暂不支持微信认证**。微信认证指引里能认证的主体是个体工商户、企业、媒体、政府及事业单位、其他组织，没有个人；支付功能又属于要认证后才有的能力。结果就是个人小程序收不了微信支付。

### 2. 只能选个人开放的服务类目

小程序上架前要设置服务类目，个人主体只能从官方给个人开放的那一份里选。截至核对日期，个人开放的类目是：

| 一级类目 | 个人能选的二级类目 |
| --- | --- |
| 工具 | 记账、日历、天气、办公、图片处理、计算器、报价/比价、信息查询、预约/报名、健康管理、备忘录 |
| 教育服务 | 教育信息展示 |
| 生活服务 | 丽人服务、家政服务、婚庆服务 |
| 商业服务 | 律师、企业管理、会展服务、摄影/扩印、公关/推广/市场调查、环保回收/废品回收 |
| 体育 | 体育培训、在线健身 |
| 物流服务 | 查件、装卸搬运 |
| 餐饮服务 | 餐厅排队 |
| 旅游服务 | 出境 WiFi |

不收钱的个人小程序，大多落在「工具」下面。你的想法挂不上任何一个，就要换主体。

### 3. 个人最多备案 5 个，上架前必须备案

新小程序**上架前必须先完成备案**，官方备案问答写明「个人主体备案小程序数量上限为 5 个」。

个人备案还有几条要注意：

- 负责人必须是本人，小程序管理员要和负责人实名信息一致。
- 服务内容不能选经营性质、企业 / 单位性质、需要主管部门前置审批的内容。
- 小程序名称要符合个人主体，不能用公司名，也不能带新闻、金融、宗教、医疗器械、网约车、校外培训这类需要前置审批的字眼。

### 4. 主体信息注册后不能改

注册流程里有一步「确认主体信息不可变更」。个人和企业选错了，这个账号改不回来。

## 小程序注册流程：5 步

官方接入指南写的注册流程：

1. 打开微信公众平台（`mp.weixin.qq.com`），点右上角「立即注册」。
2. 账号类型选「小程序」。
3. 填邮箱和密码。邮箱要求**没注册过公众平台、开放平台、企业号，也没绑定过个人微信号**。
4. 登录邮箱，点激活链接。
5. 主体类型选「个人」，填主体信息和管理员信息，确认后完成注册。

注册完先别急着写代码，按上面的判断设置服务类目，再去做备案。

## 小程序注册需要什么资料？

| 环节 | 要准备的 |
| --- | --- |
| 注册 | 一个干净的邮箱；已实名、本人年满 18 岁的微信 |
| 备案 | 本人有效身份证件；管理员人脸核验；能收短信的手机（工信部核验短信 24 小时内处理） |
| 备案（部分省份） | 身份证地址在吉林、上海、江苏、浙江、广东、四川等省份的，还要居住证明或暂住证明；以备案系统提示为准 |

通信地址要写长期居住地或户籍地址，具体到门牌号。

## 备案要多久？

官方备案问答写的时间：

| 环节 | 时长 |
| --- | --- |
| 平台初审 | 1～2 个工作日 |
| 工信部短信核验 | 你自己 24 小时内完成 |
| 省通信管理局审核 | 1～20 个工作日 |

整体按 1～4 周预估。网站的备案逻辑类似，可以对照 [ICP 备案流程](/articles/icp-filing-process/) 看各环节在做什么。

## 个人小程序能收钱吗？

用微信支付不行，原因见上面第 1 条。要收钱，有两条路：

- **办个体工商户**，用个体户身份另外注册一个小程序。个体户在可做微信认证的主体范围内。
- **先不在小程序里收钱**，用别的方式收到第一笔钱，确认有人愿意付费再办执照，见 [没有营业执照怎么收款](/articles/first-payment-without-license/)。

还在想第一个产品做多大，可以先看 [第一个产品怎么做](/articles/single-page-first/)。
