## ssh密钥是什么意思？一把锁和一把钥匙

SSH 是你的电脑（或者 AI）远程操作服务器的通道。进这个通道要验明身份，有两种办法：输密码，或者用密钥。

**SSH 密钥是成对生成的两个文件**：

| | 公钥 | 私钥 |
| --- | --- | --- |
| 像什么 | 一把锁 | 唯一能开这把锁的钥匙 |
| 放在哪 | 装到服务器上（你在控制台导入） | 只留在你自己电脑上 |
| 能不能给别人看 | 能，给云厂商、贴进控制台都没问题 | 不能，谁拿到谁就能登录你的服务器 |
| 长什么样 | 一长串文字，RSA 类型通常以 `ssh-rsa` 开头 | 一个文件，你不需要打开它 |

登录时，服务器用装好的锁去试你手里的钥匙，对得上就放行，全程不用输密码。这就是常说的「ssh免密登录」。

## <span class="role-tag me">🧑 你来做</span> 为什么用密钥，不用密码和宝塔

冬瓜的做法是：服务器上的事全部交给 Claude / Codex 通过 SSH 去做，**不用宝塔这类面板，也不用密码**。

- **不用把密码交给 AI**：AI 拿着你电脑上的私钥就能登录，你不用在对话里贴服务器密码。
- **更难被攻破**：以阿里云轻量应用服务器为例，绑定密钥并重启后，服务器会自动禁止 root 用户用密码登录，别人没法靠反复试密码进来。
- **少一层要学的东西**：不装面板，你只需要在控制台做导入、绑定、重启三件事。

## <span class="role-tag ai">🤖 交给 AI</span> 生成密钥：你只拿走公钥

把下面「交给 AI」里的第一段提示词发给 Claude 或 Codex。它会在你电脑上生成一对密钥，把公钥显示给你。

两个要点：

- **指定 RSA 类型**。阿里云轻量应用服务器导入时支持的类型里列的是 rsa、dsa、ecdsa 等，没有列 ED25519（很多教程默认生成的是 ED25519）。
- **单独起文件名，别覆盖旧密钥**。你电脑上可能已经有给 GitHub 之类用的密钥，覆盖了那边就连不上了。

要不要给私钥再加一层口令（passphrase）：<mark class="todo">待定</mark>，加了更安全，但 AI 每次连接可能要你输入，冬瓜的做法还没确认。

## <span class="role-tag me">🧑 你来做</span> 在控制台导入、绑定、重启

以阿里云轻量应用服务器为例：

1. 进控制台的**密钥对**页面，创建密钥对，选**导入已有密钥对**，把 AI 给你的公钥整段粘贴进去。
2. 在密钥对页面点**绑定实例**，选你的服务器。服务器要是「运行中」或「已停止」状态。
3. 选**立即重启**，或者稍后自己重启。**重启之后密钥才生效**。

几条规则要知道：

- **只支持 Linux 系统**的服务器这样配置。
- **一台服务器在控制台只能绑一个密钥对**，新绑定的会覆盖旧的。
- **生效后禁止 root 密码登录**。以后要重新开密码登录，得改服务器里的配置文件，交给 AI 做之前先让它说清楚后果。
- **登录用户是 root**。控制台绑定的密钥默认对应 root 用户。

然后把服务器公网 IP 发给 AI，用第二段提示词让它连上去、只看不改。连上之后，部署网站的步骤回到[服务器和部署](/flow/deploy/)接着走。

## ssh密钥认证失败怎么办

最常见的是 `Permission denied (publickey)`，意思是服务器没认出你手里的钥匙。按顺序排查：

1. **重启了吗？** 绑定后不重启，密钥不生效。
2. **用户写的是 root 吗？** 控制台绑定的密钥对应 root。
3. **AI 用的是不是那把私钥？** 电脑上有好几对密钥时，AI 可能拿错了。
4. **最近重新绑定过吗？** 一台服务器只能绑一个密钥对，新的会顶掉旧的。

每种情况怎么跟 AI 说，见下面的「卡住了怎么办」。
